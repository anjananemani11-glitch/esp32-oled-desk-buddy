# ESP32 OLED Desk Buddy 🎵

An IoT-based smart desk companion built using an ESP32 and a 1.3-inch OLED display. This project combines a real-time digital clock with Spotify now-playing information.

## ✨ Features

- Real-time clock using Wi-Fi and NTP.
- Displays date, time and seconds.
- Shows currently playing Spotify song information.
- Python-based communication between the laptop and ESP32.
- Compact OLED display interface.

## 🛠️ Hardware Components

- ESP32 DevKit
- 1.3-inch OLED Display (128 × 64)
- USB cable
- Connecting wires

## 💻 Software & Technologies

- Arduino IDE
- Python
- U8g2 Library
- PySerial
- Windows Now Playing integration

## ⚙️ Working Principle

1. ESP32 connects to Wi-Fi through a mobile hotspot.
2. NTP synchronization provides the current date and time.
3. Python retrieves currently playing media information from the laptop.
4. The information is transmitted to the ESP32.
5. The OLED display shows the clock and music information.
